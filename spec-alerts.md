# Спецификация: Система алертов и нотификаций

## 1. Назначение

Проактивное информирование участников процесса о событиях, отклонениях и дедлайнах. Алерты генерируются автоматически на основе данных из движка сверки и автогенерации план-наряда.

## 5. Правила эскалации

```
Уровень 1: РС
  ↓ (нет реакции 4 часа)
Уровень 2: ДС
  ↓ (нет реакции 8 часов)  
Уровень 3: ДП
```

| Алерт | Уровень 1 | Эскалация на Ур. 2 | Эскалация на Ур. 3 |
|-------|-----------|--------------------|--------------------|
| A02 (РС не подтвердил) | РС (06:01) | ДС (10:00) | ДП (12:00) |
| A05 (Факт не подан) | РС (20:01) | ДС (08:00+1) | — |
| A10 (Хроническое) | РС (сразу) | ДС (через 24ч) | ДП (через 48ч) |
| A15 (Просрочка) | РС (сразу) | ДС (через 24ч) | ДП (через 48ч) |

### Механизм эскалации

```python
def check_escalation(alert):
    """
    Проверяет, нужна ли эскалация алерта.
    Запускается периодически (каждый час).
    """
    if alert.acknowledged:
        return  # РС подтвердил — эскалация не нужна
    
    hours_since = (now - alert.created_at).total_hours()
    
    escalation_rules = ESCALATION_MAP[alert.alert_type]
    
    for rule in escalation_rules:
        if hours_since >= rule.after_hours and alert.escalation_level < rule.level:
            # Эскалируем
            alert.escalation_level = rule.level
            send_alert(
                recipients=rule.recipients,
                message=f"⬆️ Эскалация (уровень {rule.level})\n\n{alert.message}",
                channels=rule.channels
            )
```

## 6. Дедупликация и группировка

### 6.1. Дедупликация

- Один алерт на событие в день (не дублировать при повторном запуске сверки)
- Ключ: `(alert_type, date, housing_id, contractor_id)`
- Если алерт уже отправлен → пропускаем

### 6.2. Группировка

- Если у РС 5 подрядчиков не подали факт → **одно** сообщение со списком, а не 5 сообщений
- Если на объекте 3 критических отклонения → **одно** сообщение для ДС

```python
def group_alerts(alerts):
    """
    Группируем алерты по (recipient, housing_id, alert_type).
    """
    groups = defaultdict(list)
    for alert in alerts:
        key = (alert.recipient_id, alert.housing_id, alert.alert_type)
        groups[key].append(alert)
    
    for key, group in groups.items():
        if len(group) > 1:
            send_grouped_alert(group)
        else:
            send_alert(group[0])
```

## 7. Каналы доставки

| Канал | Когда | Формат |
|-------|-------|--------|
| Push в рапорте | Всегда | Уведомление в системе (колокольчик) |
| Telegram-бот | Если пользователь подключён к боту | Сообщение с кнопками |
| Email | Дайджест (ежедневная сводка в 21:00) | HTML-письмо |

### 7.1. Приоритеты каналов

```
critical → push + бот (немедленно) + email
warning  → push + бот (немедленно)
info     → push (немедленно) + бот (batch в 06:00 / 20:30)
```

### 7.2. Тихие часы

- **22:00–06:00** — только critical алерты
- info и warning накапливаются и отправляются утром

## 8. Хранение

```sql
CREATE TABLE alerts (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    alert_type      VARCHAR(10) NOT NULL,    -- A01, A02, etc.
    level           VARCHAR(10) NOT NULL,     -- critical, warning, info
    
    date            DATE NOT NULL,
    housing_id      UUID,
    contractor_id   UUID,
    rs_user_id      UUID,
    
    recipient_id    UUID NOT NULL,
    recipient_role  VARCHAR(20),              -- RS, DS, DP, CONTRACTOR, ADMIN
    
    message         TEXT NOT NULL,
    
    channels_sent   VARCHAR[] DEFAULT '{}',   -- ['push', 'bot', 'email']
    sent_at         TIMESTAMP,
    
    acknowledged    BOOLEAN DEFAULT FALSE,
    acknowledged_at TIMESTAMP,
    acknowledged_by UUID,
    
    escalation_level INT DEFAULT 1,
    escalated_at    TIMESTAMP,
    
    created_at      TIMESTAMP DEFAULT NOW(),
    
    UNIQUE (alert_type, date, housing_id, contractor_id, recipient_id)
);

CREATE INDEX idx_alerts_recipient ON alerts(recipient_id, created_at DESC);
CREATE INDEX idx_alerts_type_date ON alerts(alert_type, date);
CREATE INDEX idx_alerts_unacked ON alerts(acknowledged, escalation_level) WHERE acknowledged = FALSE;
```
