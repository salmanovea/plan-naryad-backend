Синхронизация с Рапортом

Полная синхронизация

Запускает синхронизацию всех справочников (users, contractors, contracts, objects, work-catalog, tech-sequence). Может занять несколько минут.

Иерархия объектов

Проекты → Объекты строительства → Корпуса → Секции → Этажи.

Каталог работ

Группы работ → Виды работ из Рапорта.

Подрядчики

Справочник подрядчиков из Рапорта.

Договоры

Плоский список договоров; подрядчик связывается по raport_id.

Тех. последовательность

Строится из календарного плана корпуса (или дефолтного шаблона). Требуется raport_id корпуса.

Факты работ

Забирает факты корпуса из Рапорта. Без даты берётся окно «вчера и сегодня» — как в ночной джобе. Требуется raport_id корпуса.
